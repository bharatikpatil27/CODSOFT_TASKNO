CODSOFT – Data Analytics Internship

PROJECT OVERVIEW
This repository showcases the practical work completed as part of my Data Analytics Internship at CodSoft. The project focuses on three important areas of data analytics: data cleaning, exploratory data analysis and data visualization using Python.

TASK 1:DATA CLEANING
Objective: To clean and prepare a raw dataset for further analysis.

WORK PERFORMED:
- Loaded the raw dataset using Pandas.
- Identified and handled missing values.
- Checked and removed duplicate records.
- Prepared the cleaned dataset for further use.
- Saved the cleaned dataset as a separate CSV file.

Output: "cleaned_dataset.csv"

TASK 2:EXPLORATORY DATA ANALYTICS(EDA)

Objective: To explore a retail sales dataset and identify useful patterns and insights.

WORK PERFORMED:
- Examined the dataset structure and summary statistics.
- Analysed missing values and duplicate records.
- Explored product category and gender-based sales.
- Examined numerical distributions and potential outliers.
- Analysed monthly sales trends.
- Generated charts and a detailed analysis report.

Output: EDA charts and "task2_report.txt"

TASK 3:DATA VISUALIZATION
Objective: To represent retail sales data through clear and meaningful visualizations.

VISUALIZATIONS CREATED:
1. Bar Chart
2. Line Chart
3. Pie Chart
4. Histogram
5. Scatter Plot
6. Combined Sales Dashboard

Output: Individual chart images and a combined dashboard saved in the "charts" folder.

TOOLS AND TECHNOLOGIES
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

CONCLUSION

Through these three tasks, I gained practical experience in preparing datasets, analysing data, identifying patterns and presenting information through visualizations.
